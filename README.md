# Afterschool Holidays

방과후학교 통합관리시스템이 학교별 API 인증키 없이 공휴일 변경사항을 확인할 수 있도록 제공하는 공개 중앙 패치 저장소입니다.

## 중앙 패치 파일

`holiday-patch.json`

학교 프로그램은 기본 공휴일을 자체 계산하고 내장 월력자료를 안전망으로 사용합니다. 이 중앙 파일에는 공식자료에서 확인된 예외사항을 반영합니다.

## 공식자료 자동검증

GitHub Actions의 `Holiday Official Source Monitor`가 매일 대한민국 표준시 기준으로 다음 공개 자료를 확인합니다.

1. 국가법령정보센터 `관공서의 공휴일에 관한 규정`
2. 한국천문연구원 `월력요항`의 공식 발표 여부
3. 한국천문연구원 `달력자료`의 국경일·공휴일 표

자동화는 첫 실행에서 기준 상태만 저장하고 중앙 패치를 변경하지 않습니다. 이후 변경을 감지하면 공식 월력요항 발표 여부와 달력자료 파싱 신뢰도를 함께 확인합니다.

### 안전 원칙

- 법령 본문이 변경되면 자동패치를 중지하고 검토가 필요한 상태로 남깁니다.
- 공식 발표가 확인되지 않은 미래 자료는 자동 반영하지 않습니다.
- 임시공휴일·선거일·대체공휴일처럼 신규 추가가 명확한 경우만 자동 추가 후보로 사용합니다.
- 기존 공휴일 삭제나 명칭 변경은 자동으로 하지 않습니다.
- 한 번에 많은 변경이 감지되거나 자료 형식이 달라지면 자동 반영하지 않습니다.
- 안전조건을 모두 통과한 변경만 `holiday-patch.json`에 자동 반영합니다.

안전조건을 통과하지 못한 변경은 GitHub Issue `공휴일 자동검증 검토 필요`로 남겨 수동 확인할 수 있습니다.

## 형식

- `schema`: 패치 형식 버전
- `version`: 패치 버전
- `referenceDate`: 확인 기준일
- `replaceYears`: 해당 연도의 내장 기준을 중앙 자료로 교체할 때 사용하는 연도 목록
- `holidays`: 추가 또는 교체할 공휴일 목록
- `removeDates`: 기존 공휴일에서 제외해야 할 날짜 목록

학교 담당자가 별도의 공공데이터 API 인증키를 입력할 필요는 없습니다.
