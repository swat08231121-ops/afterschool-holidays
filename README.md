# Afterschool Holidays

방과후학교 통합관리시스템이 학교별 API 인증키 없이 공휴일 변경사항을 확인할 수 있도록 제공하는 공개 중앙 패치 저장소입니다.

## 중앙 패치 파일

`holiday-patch.json`

프로그램은 기본 공휴일을 자체 계산하고 기존 월력자료를 안전망으로 사용합니다. 이 중앙 파일에는 임시공휴일, 선거일, 법령 변경 등 공식적으로 확인된 예외사항만 추가합니다.

## 형식

- `schema`: 패치 형식 버전
- `version`: 패치 버전
- `referenceDate`: 확인 기준일
- `replaceYears`: 해당 연도의 내장 기준을 중앙 자료로 교체할 때 사용하는 연도 목록
- `holidays`: 추가 또는 교체할 공휴일 목록
- `removeDates`: 기존 공휴일에서 제외해야 할 날짜 목록

학교 담당자가 별도의 공공데이터 API 인증키를 입력할 필요는 없습니다.
